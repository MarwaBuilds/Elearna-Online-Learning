# Netlinks Learning website

A responsive React + Vite recreation of the supplied Elearna Home One reference, branded for **Netlinks**, **Marwa Azizi**, and **Instructor Gula Khan Hamdard**.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` for a production build.

## Included
- Responsive desktop, tablet, and mobile layouts
- Original supplied image, SVG, logo-strip, and background assets
- Sticky navigation and mobile menu
- Smooth section scrolling and scroll reveal effects
- Interactive course category filters and search
- Testimonial slider controls
- Reusable course data and component-driven React structure
- Keyboard-friendly buttons, labels, alt text, and reduced-motion support

## Notes
This is a front-end starter. Course enrolment, authentication, checkout, CMS editing, and contact form submission require real backend services and have not been connected. Replace the sample course copy, contact email, and metrics with approved Netlinks details before publishing.
